## Corrections and evidence

- **e-Sports & Music Festival Hong Kong 2019**: Edition matched from the recalled PUBG Mobile and CS:GO tournament lineup; team experience before Imagine Division was established. [Reference](https://partnernet.hktb.com/filemanager/intranet/pm/PressRelease/EnglishPress/Press%20Release%202019/07-EMFHK%20Press%20Release%20-%2026%20July%20-%20E.pdf).
- **InnoHK 創新香港研發平台啟動禮**: Supplied production date/range: 24–25 May 2022; public event date: 2022-05-25. [Reference](https://www.innohk.gov.hk/en/spotlights/news/news25may/).
- **中醫醫院及政府中藥檢測中心動土典禮**: Supplied production date/range: 1–2 Jun 2022; public event date: 2022-06-02. [Reference](https://www.info.gov.hk/gia/general/202206/02/P2022060200346.htm).
- **慶祝香港回歸祖國25週年暨香港友好協進會成立33週年音樂晚會**: Supplied production date/range: 21 Jun 2022; public event date: 2022-06-21. [Reference](https://fhka.com.hk/「慶祝香港回歸祖國25週年-暨-香港友好協進會成立33/).
- **國際母乳哺育周2022線上慶祝活動**: Supplied production date/range: 28–29 Jul 2022; public event date: 2022-07-29. [Reference](https://unicef.org.hk/zh-hant/news/latest_news/online-celebration-world-breastfeeding-week-2022).
- **香港中藥材標準國際專家委員會第12次會議**: Supplied production date/range: 15–16 Aug 2022; public event date: 2022-08-16. [Reference](https://www.info.gov.hk/gia/general/202208/17/P2022081600556.htm).
- **Revive Tech Asia 2022 亞洲商業科技展**: Supplied production date/range: 22–25 Aug 2022; public event date: 2022-08-24 – 2022-08-25. [Reference](https://space.hk01.com/organizer/891/revive-tech-asia-limited).
- **第四屆粵港澳大灣區中醫藥傳承創新發展大會**: Supplied production date/range: 24–25 Aug 2022; public event date: 2022-08-25. [Reference](https://www.info.gov.hk/gia/general/202208/25/P2022082500605.htm).
- **Luminous Lodge 01 綜合同人展**: Supplied production date/range: 27–28 Aug 2022; public event date: 2022-08-27 – 2022-08-28. Postponed from 12–13 February; the original Klook poster retains the earlier dates. [Reference](https://hkdoujin.com/2022/08/11482/).
- **HKPC ForeSight 2023 — 智瞻2023：經濟開新篇・科技創優勢**: Supplied production date/range: 1 Dec 2022; public event date: 2022-12-02. [Reference](https://www.info.gov.hk/gia/general/202212/02/P2022120100406.htm).
- **Mic On Project 1st Live Concert**: Exact date corroborated by performer histories; organizers are recorded in the existing portfolio. [Reference](https://hkvtuber.fandom.com/zh-tw/wiki/小林冰).
- **「『帶路』文化聚香江」文化晚宴**: 2024 edition confirmed by the project owner and archived portfolio. [Reference](https://www.wenweipo.com/s/202412/04/AP6750445de4b073da47a64215.html).
- **hololive English Party2Gether**: Party2Gether is the event branding; the existing case page keeps its original URL. [Reference](https://myfigurecollection.net/item/3473684).
- **Virtual Carnival 2025**: Public listing names the event brand; the legal organizing entity is unconfirmed. [Reference](https://www.klook.com/zh-HK/event-detail/101029173-2025-virtual-carnival/).

HKGCC, rather than HKGC, and the 2024 dinner edition were confirmed by the project owner. The e-sports 2019 match is an inference from the owner's PUBG Mobile and CS:GO recollection, corroborated by the HKTB release and [CGA tournament rules](https://vs.cga.gg/tournament/PUBGMEMFHK2019).
